# Mis comidas

Aplicación personal para registrar almuerzo y cena a **S/ 11.00** cada uno.

## Usarla en un iPhone

1. Crea un repositorio vacío en GitHub, por ejemplo `proyectocomida`.
2. En esta carpeta, conecta ese repositorio y sube el contenido a la rama `main`.
3. En GitHub, ve a **Settings → Pages → Build and deployment** y selecciona **GitHub Actions**. El archivo `.github/workflows/deploy-pages.yml` publicará la app automáticamente.
4. Abre el enlace que GitHub mostrará (algo como `https://tu-usuario.github.io/proyectocomida/`) con **Safari** en el iPhone.
5. Pulsa Compartir y elige **Añadir a pantalla de inicio**.

La app se abrirá como una aplicación normal y seguirá disponible sin conexión después de la primera visita. Los registros quedan guardados en ese dispositivo y navegador.

## Importante

Para no perder los registros si cambias de teléfono o borras los datos de Safari, habría que añadir respaldo en la nube. WhatsApp puede servir para recibir mensajes, pero requiere crear y alojar un bot; para este caso, esta app local es mucho más simple y no tiene costo mensual.
